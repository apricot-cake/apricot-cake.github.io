# Fandocker

作品・キャラの親子タグで画像を管理するローカルツールです。タグはYAMLに保存し、画像のコピー・移動は行いません。

## 起動

`tools/fandocker/` で初回に `npm install` を実行します。以後は同じフォルダーで `start.vbs` または `npm start` を実行します。URLは http://127.0.0.1:4317 です。

## 操作

「フォルダー選択」で画像フォルダーを開きます。作品・キャラの検索欄からタグを選択・新規作成できます。キャラを選ぶと選択画像にタグが付きます。

Enterで次の画像、Backspaceで前の画像、1で作品、2でキャラの検索を開きます。検索中は上下キーで候補を選び、Enterで確定します。Ctrlクリック・Shiftクリック・チェックボックスで複数選択できます。Ctrl+Zで取り消し、Ctrl+Yでやり直しできます。

「フィルタ」でタグ付け状態・作品・キャラ、「表示」で並び順とサムネイルサイズを変更できます。

## 保存

タグと画像への割り当ては画像フォルダー内の `catalog.yaml` に自動保存します。保存前の内容は `catalog.yaml.bak` に保持します。`TAGGER_IMAGES` で初期画像フォルダー、`TAGGER_DATA` で初期データ保存先を変更できます。

旧フォルダー分類版の `.tagger-catalog.json` がある場合は、その最新のタグ編集をYAMLへ移します。移行前のYAMLとJSONは識別子付きの `.bak` ファイルに退避します。以前コピーした画像や整理先フォルダーには変更を加えません。

## 検証

`npm run build`、`npm run lint`、`npm test` を実行します。
