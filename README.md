# Fandocker

React・TypeScript・Vite・shadcn/ui（Radix）・Tailwind CSSによるローカル画像整理ツールです。

## 起動

初回は `npm install`、以後は `start.vbs` または `npm start` で起動します。URLは http://127.0.0.1:4317 です。画面はHMRで更新されます。サーバー変更は再起動が必要です。

## フォルダー分類

1. 「フォルダー選択」で元画像を開きます。
2. 「整理」→「整理先を選択」で保存先を選びます。OSの選択画面から新規フォルダーも作成できます。
3. 画像を選択し、作品・キャラの検索欄で分類先を指定します。検索欄から新しい名前も作成できます。
4. 「選択画像を分類先へコピー」で `整理先/作品/キャラ/画像` にコピーします。元画像は残ります。複数のキャラを付けた場合は各フォルダーにコピーします。

整理先に同じSHA-256の画像があれば分類済みと判定します。名前が違っていても一致します。既存画像の作品・キャラはフォルダーから読み取り、フィルターにも反映します。作品・キャラの2階層を対象とし、整理先直下の画像も分類済み判定の対象です。シンボリックリンクは追跡しません。

同じ分類先に同一内容の画像があればコピーを省略します。同名で内容が異なる画像は連番を付けて保存し、上書きしません。「再確認」で外部での移動・削除を反映できます。元画像と整理先は互いに含まれない別フォルダーを指定します。

「整理」→「作品・キャラ名を編集」で対応するフォルダーも改名します。同名フォルダーとの統合は行いません。外部のファイル管理ソフトで名前を変えた場合、古い分類候補は自動で削除されません。

## 取り消し

分類先の指定はCtrl+Z、Ctrl+Yで取り消し・やり直しできます。ファイルのコピーとは別の履歴です。

コピーは「整理」→「コピーを取り消す」で直前のコピーを取り消せます。既に存在した画像は削除しません。コピー後に内容が変更された画像がある場合は停止します。履歴は起動中のみ保持し、整理先切り替え・分類名変更・再起動でリセットします。作成した空フォルダーは残します。

## 操作

Enterで次の画像、Backspaceで前の画像。1で作品、2でキャラの検索を開きます。検索中は上下キーで候補を選び、Enterで確定します。Ctrlクリック・Shiftクリック・チェックボックスで複数選択できます。

「フィルタ」に分類状態・作品・キャラ、「表示」にソートとサムネイルサイズがあります。表示設定はブラウザーに記憶します。

## 保存と互換性

分類先の指定は画像フォルダー内の `.tagger-catalog.json`、整理先は `.tagger-destination.json` に保存します。JSONがなければ従来の `catalog.yaml` を読み込みます。元のYAMLは残し、以後の変更はJSONへ保存します。YAMLは「整理」から書き出せます。

`TAGGER_IMAGES` で初期画像フォルダー、`TAGGER_DATA` で初期データ保存先を変更できます。フォルダー切り替え後は選択先に保存します。

## 検証

`npm run build`、`npm run lint`、`npm test` を実行します。テストは一時フォルダーで保存、復元、コピー、重複判定、取り消し保護、名前変更を検証します。
